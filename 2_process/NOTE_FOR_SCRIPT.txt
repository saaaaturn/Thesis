NOTE KHI CHAY SCRIPT

Quy uoc nhanh:
- Single mode: dung --circuit-file, KHONG can --circuit-pool.
- Multiple mode: dung --circuit-file + --circuit-pool.
- Khong con preset; nhap truc tiep cac tham so reward, penalty, scale, lr, ent_coef.
- Muc tieu chinh LUT6-only: dung --reward-alpha 1.0 --reward-beta 0.0.
- Best checkpoint theo LUT6: dung --best-by lut6.

1) TRAINING TU DAU

Single mode:
python train_hybridsyn_ppo.py \
	--mode single \
	--circuit-file ../1_inputs/EPFL_benchmarks/arithmetic/adder.aig \
	--sequence-steps 25 \
	--total-actions 30000 \
	--ppo-steps 300 \
	--batch-size 60 \
	--learning-rate 0.0008 \
	--gamma 0.99 \
	--gae-lambda 0.95 \
	--clip-range 0.2 \
	--ent-coef 0.005 \
	--vf-coef 0.5 \
	--seed 42 \
	--device auto \
	--reward-alpha 1.0 \
	--reward-beta 0.0 \
	--step-penalty 0.0 \
	--reward-scale 10.0 \
	--reward-clip 10.0 \
	--best-by lut6 \
	--enforce-clean-signal \
	--log-file-name train_single_lutlevel.log \
	--eval-freq 2000 \
	--eval-episodes 5 \
	--save-freq 2000 \
	--progress-bar
